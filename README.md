# Bordereau — dossier de cadrage

Service de facturation pour infirmières libérales (IDEL), Jura / Doubs.
Ce dépôt est le **cahier des charges** : il sert de base à la construction, avec Claude Code, d'une **application d'apprentissage et d'aide à l'organisation pour débuter** (pas de gestion d'activité).

*Dernière mise à jour : 29/09/2026 — statut : première version, à relire.*

## Comment lire ce dossier
| Fichier | Contenu |
|---|---|
| `decisions.md` | Ce qui est tranché (ne pas redemander) |
| `questions-ouvertes.md` | Ce qui reste à trancher, par priorité |
| `docs/00-vision-et-perimetre.md` | Objectif, périmètre, hors périmètre |
| `docs/01-statut-juridique.md` | Statut, formalités, assurances |
| `docs/02-metier-ngap-et-facturation.md` | Compétences métier à acquérir |
| `docs/03-logiciels.md` | Logiciels IDEL, accès distant, maquette |
| `docs/04-clients-et-offre.md` | Trouver et gérer les clientes, tarification |
| `docs/05-donnees-et-securite.md` | RGPD, CPS, responsabilité |
| `docs/06-cas-usage.md` | Cas d'usage d'une IDEL et de la facturation (approche éditeur) |
| `docs/07-app-apprentissage.md` | Plan du site (6 pages) et pistes de spécification |
| `docs/08-feuille-de-route.md` | Feuille de route de démarrage (affichée sur l'accueil) |
| `docs/sources.md` | Sources consultées |
| `app/` | L'application (PWA) — voir `app/README.md` |

## Règles de tenue du dossier
- Une décision prise va dans `decisions.md` avec sa date.
- Une question ne se pose qu'une fois : elle vit dans `questions-ouvertes.md` jusqu'à réponse.
- Tout chiffre ou règle réglementaire non vérifié est marqué **[à vérifier]**.
- Aucune donnée patient dans ce dépôt, jamais.
